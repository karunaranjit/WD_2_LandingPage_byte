# Flowly — Landing Page

A responsive landing page for a fictional productivity app, built as part of the AVIP 2026 Web Development track.

## Features
- Hero section with clear call-to-action
- Feature grid with hover animation (interactive element)
- CTA section
- Fully responsive (desktop, tablet, mobile)
- Proper meta tags for SEO

## Tech
HTML, CSS (no frameworks)

## Run it
Open `index.html` in a browser, or use Live Server in VS Code.
